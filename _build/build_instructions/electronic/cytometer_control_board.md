# Cytometer Main Board

#### For the Cytkit 2S-14F configuration, coming soon!

Main Board for building a cytometer comprising:

- 16 channels voltage input analogue-to-digital converters (ADC)
- 16 channels reference voltage output for detectors digitally controlled (DAC)
- 16 channels bias voltage output for detectors digitally controlled (DAC)
- DC motor controller for sheath pump (to control voltage-based pumps for positive pressure or vacuum)
- Stepper motor controller for sample pump (to control stepper-based peristaltic or syringe pump)
- 5V stabile voltage power supply for laser
- Fan controller for thermal management of instrument
- Laser power supply
- FPGA with triggering firmware for real time digital signal processing 
- OLED display controller (SPI)
- USB communication chip for input / output to host PC
- USB hub for connecting on-board camera
- 2 x interlock connections for switching off laser if enclosure is opened
- 2 x PD Board connections
- 1 x SiPM Board biases and references connection
- 1 x SiPM Board signal connection
- 1 x Laser power connection
- 1 x Stepper motor connection
- 1 x DC motor connection
- 1 x Fan connection
- 2 x USB connections

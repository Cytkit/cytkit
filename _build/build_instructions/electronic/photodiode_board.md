# Photodiode Board

#### For the Cytkit 2S-14F configuration, coming soon!

Detector board containing:

- one silicon photodiode (PD), suitable for detecting forward or side scatter, either as positive (dark field, true small/wide angle light scatter) or negative (occultation, light loss, brightfield)
- analog electronics for the PD chip, comprising reference voltage connection, transimpedance amplifier and voltage output
- ribbon connector for power, reference and voltage output to the Main Board

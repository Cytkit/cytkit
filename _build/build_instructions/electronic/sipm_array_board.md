# SiPM Array Board

#### For the Cytkit 2S-14F configuration, coming soon!

Detector board containing:

- one row of 14 silicon photomultipliers (SiPM) suitable for detecting a full spectrum of fluorescence emission 
- analog electronics for each individual SiPM chip, comprising bias voltage connection, reference voltage
connection, transimpedance amplifier and voltage output
- ribbon connectors for bias voltage and reference voltage controls and voltage outputs to the Main Board
